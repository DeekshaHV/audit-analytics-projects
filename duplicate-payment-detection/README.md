# Duplicate Payment Detection

## Business Problem
Organizations may accidentally process duplicate invoices,
leading to financial leakage and weak financial controls.

## Objective
Identify duplicate vendor payments using Python and audit analytics.

## Audit Risks
- Duplicate invoices
- Fraudulent payments
- Weak AP controls

## Tools Used
- Python
- pandas
- CSV datasets

## Planned Features
- Duplicate invoice detection
- Vendor analysis
- Risk scoring
- Exception reporting
